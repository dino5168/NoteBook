## 3. 集合運算 (Set Operations)

這是 Set 最強大的地方，可以用來比較兩個群體之間的關係。

|**運算類型**|**符號**|**說明**|
|---|---|---|
|**交集 (Intersection)**|`&`|找出兩個集合中「共同擁有」的元素|
|**聯集 (Union)**|`\|`|合併兩個集合，並去除重複項|
|**差集 (Difference)**|`-`|存在於 A 但不存在於 B 的元素|
|**對稱差集 (Symmetric Difference)**|`^`|只存在於 A 或只存在於 B 的元素（扣除共同部分）|
