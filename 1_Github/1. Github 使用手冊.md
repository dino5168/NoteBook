### 產製完成之後 本機使用
![][git_first_command.png]]

``` bash
echo "# NoteBook" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/dino5168/NoteBook.git
git push -u origin main
```

2. **`git init`**
    
    - 初始化一個新的 Git 倉庫（repository）。
    - 它會在當前目錄下創建一個 `.git` 資料夾，用來追蹤版本和管理 Git 相關資料。
    

---

3. **`git add README.md`**
    
    - 將檔案 `README.md` 加入 **暫存區（staging area）**，準備提交（commit）。
    - 只有被加入暫存區的檔案，才會被下一次的 commit 記錄。

---

4. **`git commit -m "first commit"`**
    
    - 提交暫存區的檔案到 Git 倉庫的歷史紀錄中。
    - `-m "first commit"` 是提交的訊息，說明這次提交的內容或目的。
    - 這裡 `"first commit"` 通常是專案的初始提交。
        

---

5. **`git branch -M main`**
    
    - 將當前分支重命名為 `main`（通常現代 Git 倉庫的預設主分支名稱）。
        
    - `-M` 表示強制重命名，即使已經存在分支也會覆蓋。
        

---

6. **`git remote add origin https://github.com/dino5168/NoteBook.git`**
    
    - 設定遠端倉庫（remote repository）連結，命名為 `origin`。
        
    - 這樣 Git 就知道未來要把本地的 commit 推送到哪裡。
        
    - 這裡的 URL 是你 GitHub 上的倉庫位置。
        

---

7. **`git push -u origin main`**
    
    - 將本地的 `main` 分支推送到遠端 `origin` 倉庫。
        
    - `-u` 表示設置 **上游分支（upstream branch）**，這樣之後你可以只用 `git push` 或 `git pull` 而不用再指定遠端和分支。
